# Paleta de colores — Grupo TFP Chile

Derivada directamente del logo oficial. No incluye negro puro en los tonos primarios.

## Primarios

| Token        | HEX       | Uso                                                                 |
|--------------|-----------|---------------------------------------------------------------------|
| `--navy`     | `#1F3557` | Azul marino profundo. Texto principal, titulares, acentos serios.   |
| `--steel`    | `#6E88A6` | Azul acero medio (del rectángulo del logo). Botones y elementos activos. |

## Neutros

| Token        | HEX       | Uso                                                |
|--------------|-----------|----------------------------------------------------|
| `--ink`      | `#1E2A3B` | Texto principal (azulado oscuro, no negro puro).   |
| `--muted`    | `#5C6B7E` | Texto secundario, metadatos.                       |
| `--bg`       | `#FFFFFF` | Fondo principal.                                   |
| `--bg-alt`   | `#F4F7FA` | Fondos alternos para seccionar.                    |
| `--line`     | `#E4EAF0` | Bordes, líneas divisorias (del recuadro inferior). |

## Acento

| Token        | HEX       | Uso                                                |
|--------------|-----------|----------------------------------------------------|
| `--accent`   | `#C9A67B` | Beige cálido. Subrayados, detalles, hover states.  |
